One word, first thought: **tsundoku** — buying books and letting them pile up unread. A single word that carries a whole funny, relatable story in one beat: the buyer, the tower of unread books, the good intentions. Chosen from a shortlist of 25 candidates for surprise, vividness and wit, deliberately steering clear of the field's saturated picks (petrichor, defenestration, apricity). No topic, no explanation, no second draft — just the word.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` and verifies the file holds exactly that one word, one line, ASCII only.
